Training sources are dedented code from the supplied notebook. elmo_textcnn.py is the base layer-mix/projection/CNN implementation. optimize_elmo_textcnn.py adds the distinct local/global head variants. run_experiments.py contains the A/B/C/D experiment, with only path, wrapper and output-directory adjustments. A is weighted local/global, B removes the global branch, C removes class weights, and D applies offsets selected on inner OOF predictions from A. Five outer folds use 591 training rows, three inner folds select offsets. The historical 397-row development result has a different protocol.
