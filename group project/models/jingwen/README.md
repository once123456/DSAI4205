# Jingwen 的情感分类模型 · 多指令视角 embedding + 多核 SVM

本部分研究：只有几百条标注推文时，怎样从一个冻结的文本编码器里得到更好的表示，再交给一个独立的分析模型分类。表示模型是 `intfloat/multilingual-e5-large-instruct`（冻结，不做本任务训练），分析模型是在本项目数据上从头训练的**多核支持向量机（multi-kernel SVM）**。两者完全分开，符合课程“嵌入模型与分析模型独立”的要求；分析模型属于核方法，与小组其他成员的 MLP 不同。[课程建模要求](../../Project%20description%20%281%29.pdf)

## 方法

1. **多指令视角。** 同一条推文配上不同的任务说明，分别编码，得到多个视角的向量：情感（对所提品牌或游戏的态度）、话题、文体（新闻、转发链接还是个人观点）。每个任务用两种措辞（prompt ensemble），共 6 个 1024 维视角，均做 L2 归一化。
2. **多核融合。** 每个视角各算一个 RBF 核，6 个核等权相加，送入 SVM（`class_weight="balanced"` 处理类别不平衡）。
3. **选型。** 所有设计和超参数都用训练池 591 条（train 473 + validation 118）上的 5 折×3 次重复交叉验证选择；测试标签只在 `final_eval.py` 中读取一次。

## 运行

使用 conda 环境 `dsai4205`（torch、transformers、scikit-learn、pandas、ftfy、matplotlib），在本目录执行：

```bash
python final_eval.py     # 编码（首次下载模型，之后读缓存）、按交叉验证选 C、在测试集评估一次并导出结果
python figures.py        # 由导出结果生成报告图
```

单张 RTX 4090 上首次运行约 2 分钟，之后读缓存约 15 秒。向量缓存默认写在 `runs/jingwen/work/`（已被 `.gitignore` 排除），可用环境变量 `JINGWEN_WORK_DIR` 改到别处。

## 数据与评估

与小组口径一致：固定划分 473 训练 / 118 验证 / 397 测试，模型输入为 `Phrase` 轻度修复编码后的文本，主指标 macro-F1，同时报告 accuracy、逐类指标、混淆矩阵和相对共享基线的配对 bootstrap 区间（1000 次）。SVM 与冻结编码器都是确定性的，因此不需要多种子。另外报告去掉 25 条“在训练池中有改写版本”的测试推文后的成绩（372 条），检验提升是否来自泄漏。

## 结果（测试集 397 条）

| 模型 | 训练条数 | accuracy | macro-F1 | 去掉改写泄漏后 macro-F1 |
|---|---:|---:|---:|---:|
| TF-IDF + LR（共享基线） | 473 | 0.4912 | 0.4461 | 0.4165 |
| bge-large + SVM | 473 | 0.5743 | 0.5382 | 0.5063 |
| 单一情感指令视角 + SVM | 473 | 0.5592 | 0.5242 | 0.4993 |
| 三任务视角 + 多核 SVM | 473 | 0.6096 | 0.5903 | 0.5733 |
| 六视角 prompt ensemble + 多核 SVM | 473 | 0.6071 | 0.5793 | 0.5629 |
| TF-IDF + LR（共享基线，完整训练池） | 591 | 0.5063 | 0.4662 | 0.4286 |
| **最终模型：六视角，用全部 591 条训练** | 591 | **0.6222** | **0.5974** | **0.5805** |

相同 473 条训练时，六视角模型比共享基线高 13.3 个百分点（95% 配对 bootstrap 区间 [7.9, 18.6]）；都用 591 条训练时高 13.1 个百分点（[7.4, 18.7]）。最后一列去掉与模型训练数据近似重复（词集 Jaccard ≥ 0.5）的测试推文：473 条训练的模型去掉 23 条，591 条训练的模型去掉 25 条。三视角与六视角在测试集上相差约 1 个百分点，在噪声范围内；六视角由交叉验证选定（与只用第二种措辞的 0.5647 基本持平，取更稳定的 prompt ensemble）。

## 迭代中尝试但未采用的做法

| 尝试 | 交叉验证结果 | 原因 |
|---|---|---|
| 监督式对比学习微调编码器（SupCon） | 验证集持续下降 | 473 条话题集中的数据上，对比学习把同话题而非同情感的推文拉近 |
| 实体遮蔽视角、BERT-whitening、类原型与近邻特征、EDA 表层特征 | 无提升 | 信息已被指令视角覆盖 |
| 拼接或核相乘替代核相加、线性或多项式核 | 持平或更差 | 融合方式影响很小，关键在视角本身 |
| 按类决策偏置校准（嵌套交叉验证） | −0.6 个百分点 | 4 个偏置在小样本上过拟合 |
| 置信学习式标签噪声过滤（去掉 3% 到 15%） | −0.7 到 −1.3 个百分点 | 同时删掉了难但正确的样本；被标出的样本可用于定性分析 |
| gemma-3-4b 改写增强 | +0.4 个百分点，仅约一半折提升 | 收益不稳定，改写多样性有限 |
